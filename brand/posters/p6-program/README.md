# P6 · 프로그램 안내 포스터

캔버스 보드 PosterProgram의 선 그림을 만드는 스크립트. 긴 테이블에 둘러앉은 막대 인물, 테이블 위
이야기 카드, 말하는 사람 입에서 피어나는 꽃(이야기가 피어나는 곳).

- `python3 build.py > prog.json` → `svg` 문자열을 보드의 `<g transform="translate(0 -104)">` 안에 넣는다.
- 인물은 `sitter()`(뒷줄)와 양 끝 스툴 인물로 나뉜다. 머리 모양은 spikes · long · curls · bun · fringe.
- 테이블은 라임으로 칠해 뒤에 앉은 사람의 몸을 가린다. 라임 패널 위라 같은 색이 된다.

레퍼런스는 Re-Offline Studio(reoffline.com)의 워크숍 포스터다. 파란 선 그림 + 프로그램 안내라는
아이디어만 가져왔고, 화면 구성은 다르게 했다(가이드북식 머리줄, 라임 패널 안의 그림, 아래 시간표).
