# P4 · 말랑한 글자

캔버스 보드 PosterPuff의 글자 배치를 만드는 스크립트. 글자를 글꼴이 아니라 일러스트로 다룬다.

- 글자마다 폭(`rows`)을 정하고, 높이는 위아래 글자에 맞물리게 계산한다.
  윗줄 글자의 바닥 바로 아래에서 시작하고(skyline), 바닥선은 글자마다 번갈아 높고 낮다(`base` ± `amp`).
  그래서 위에서 길게 내려온 글자 밑에는 짧은 글자가 온다.
- `modak-glyphs.json`은 Modak 300px의 실제 잉크 경계(x, y, w, h). 글자를 상자에 꼭 맞게 늘릴 때 쓴다.
- 실행: `python3 build.py > puff.json` → `svg` 문자열을 보드의 `<svg role="img">` 안에 넣는다.
  표준 오류에 글자별 높이가 찍힌다. 150px 아래로 내려가면 너무 납작하다.
