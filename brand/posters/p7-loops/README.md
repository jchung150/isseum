# P7 · 고리 글자

캔버스 보드 PosterLoops를 만드는 스크립트. 큰 글자 ISSEUM(IS / SE / UM)을 굵은 한 줄 획으로 그려
기울이고 가장자리에서 자르고, 그 틈에 밑줄 친 작은 안내 블록을 놓는다.

- `python3 build.py > loops.json` → `svg`는 보드의 큰 글자 `<g>` 안에, `html`은 그 아래에 넣는다.
- 글자와 블록이 같은 코발트라 블록이 글자 위에 얹히면 사라진다. 블록은 반드시 틈에 둔다.
- I에 고리를 넣어 봤지만 폭이 좁아 고리 안쪽이 메워졌다. I는 곧은 획.
- 블록 내용(OPEN STUDIO DAY, SAT 05.12 14H–20H, STORY TABLE · ZINE MAKING · LISTENING ROOM)은 지어낸 예시. 주소는 실제 주소.

## 2026-11-13 · Recraft 글자로 교체

보드는 이제 `p7-letters.png`(소유자가 Recraft로 만든 I S / S e / U m)를 쓴다. build.py의 코드 글자는 더 쓰지 않는다.

- 원본은 노랑 바탕에 남색. 빨강 채널로 0..1 값을 만들어 코발트 #0526C5 ↔ 라임 #EAFDA1로 다시 칠했다(가장자리 계조 유지).
- 첫 줄 I와 S 사이에 글자가 아닌 기울어진 막대가 하나 더 있어 "IIS"로 읽혔다. 원본 832×1280 기준 x 308–408, y 0–412를 바탕색으로 지웠다.
- 보드: 높이 1680에 맞춰 폭 1092, left 48. 바탕이 같은 라임이라 양옆 띠가 보이지 않는다.
- 작은 블록은 글자 안쪽 빈 곳에 넣었다: I의 양쪽(ISSEUM PRESENTS · 날짜), 지운 막대 자리(OPEN STUDIO DAY, 세로), U 안(주소), m의 두 아치(프로그램).
