# P5 · 손으로 쓴 글자

캔버스 보드 PosterSlow의 글자를 만드는 스크립트. 글꼴을 쓰지 않고 글자를 직접 그린다.

- 글자마다 뼈대 선(`SK`, 0..100 상자)을 굵은 둥근 마커(`STROKE`)로 긋는다. `vector-effect`로
  글자를 늘리거나 눌러도 선 굵기는 그대로다.
- 글자마다 폭 · 높이 · 기울기(±7°) · 위아래 흔들림(±16px)이 다르다. 시드를 바꾸면 다른 배치가 나온다:
  `python3 build.py 12`.
- 손맛은 보드의 SVG 필터가 낸다: 낮은 주파수 노이즈로 가장자리를 흔들고(feDisplacementMap),
  높은 주파수 노이즈로 크레용 질감을 뚫는다. 질감이 너무 성기면 feColorMatrix 마지막 줄의 값을 올린다.
- 둥글게: 필터가 흔든 뒤 살짝 흐리고(feGaussianBlur 5) 알파를 다시 세워(feFuncA slope 10, intercept -4.8)
  모서리를 둥글린다. intercept를 올리면 획이 두꺼워져 안쪽이 메워진다.
- 뭉치게(2026-11-13): 줄마다 폭에 맞춰 늘리지 않고 모든 줄을 같은 크기(`SIZE`)로 두어 줄 길이가
  들쭉날쭉하다. 글자 사이는 -10px(`GAP`)로 맞닿고, 줄 간격(`STEP` 186)이 글자 높이(`ROW_H` 222)보다
  작아 윗줄과 아랫줄이 겹쳐 물린다. 덩어리는 세로 가운데에 놓인다. 마커 46px, 기본 시드 21.
  안쪽이 메워지는 글자(N · E · G)가 생기면 시드를 바꿔 본다.
