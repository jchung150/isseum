# 이씀 사진 보정

인스타그램 · 스토리 · 사이트에 올리는 사진은 모두 이 보정을 거친다. 같은 날 찍은 것처럼
색이 맞아야 피드가 한 브랜드로 보인다. 처음 쓴 곳: 2026-11-13 '결' 세미나 후기 캐러셀.

## 왜 보정하나

이씀 사진은 대부분 천장 형광등 아래에서 휴대폰으로 찍는다. 그래서

- 전체가 회색빛으로 가라앉고(가장 어두운 곳도 진한 검정이 아니고, 가장 밝은 곳도 흰색이 아니다)
- 나무 벽 · 화분 · 소품의 색이 죽는다.

보정은 이 두 가지만 되돌린다. 필터처럼 분위기를 바꾸지 않는다.

## 보정 값 (순서대로)

| 단계 | 값 | 하는 일 |
|---|---|---|
| 1. 방향 | EXIF 회전을 픽셀에 적용 | 갤럭시 사진이 옆으로 눕지 않게 |
| 2. 레벨 | 가장 어두운 1% → 검정, 가장 밝은 0.5% → 흰색 | 회색빛을 걷어 낸다 |
| 3. 밝기 · 채도 | 밝기 ×1.04, 채도 ×1.24 | 조금 밝게, 색은 확실히 |
| 4. 대비 | ×1.06 후 −6 | 검정이 다시 뜨지 않게 |
| 5. 색온도 | 빨강 ×1.025, 파랑 ×0.97 | 살짝 따뜻하게 |

**색온도는 이 이상 올리지 않는다.** 빨강 ×1.05 · 파랑 ×0.94로 해 봤을 때 흰 벽이 누렇게 떴다.

## 쓰는 법 (정확한 방법)

저장소 폴더에서:

```bash
# 인스타그램 피드(4:5)
node brand/photo-grade/grade.mjs <사진 또는 폴더> --out <저장할 폴더> --size 1080x1350

# 스토리(9:16)
node brand/photo-grade/grade.mjs <사진 또는 폴더> --out <저장할 폴더> --size 1080x1920

# 사이트용(비율 유지, 긴 변 2000px)
node brand/photo-grade/grade.mjs <사진 또는 폴더> --out <저장할 폴더>
```

`--size`를 주면 가운데를 기준으로 그 비율에 맞게 잘린다. 결과는 JPEG, 원본과 같은 이름이다.
값을 바꾸려면 `grade.mjs`의 `GRADE`와 이 표를 함께 고친다.

## 휴대폰 · 라이트룸에서 비슷하게 하려면 (근사값)

스크립트와 똑같지는 않다. 급할 때 비슷한 느낌을 내는 출발점이다.

| | 아이폰 사진 앱 | 라이트룸 |
|---|---|---|
| 회색빛 걷기 | 블랙 포인트 +10, 하이라이트 +10 | 흰색 계열 +15, 검정 계열 −10 |
| 밝기 | 밝기 +5 | 노출 +0.10 |
| 색 | 채도 +20 | 채도 +20 |
| 대비 | 대비 +8 | 대비 +8 |
| 따뜻하게 | 따뜻함 +8 | 색온도 +200K 쪽 |

## 주의

- **원본은 그대로 둔다.** 보정본은 다른 폴더에 저장한다.
- **사람 얼굴이 나오는 사진**은 게시 동의를 받은 행사만 쓴다.
- 사이트의 공간 사진(`src/assets/isseum_*.jpg`)은 전문 촬영본이라 아직 이 보정을 거치지 않았다.
  적용하려면 사이트에서 전후를 비교한 뒤 정한다.
