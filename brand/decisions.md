## 2026-11-11 · 방향의 씨앗 (소유자 답변)

  인상, 서체와 색의 활용.
- **레퍼런스 시각 언어 (HTML/CSS에서 추출, 참고용):** 흰색·검정·회색 바탕에 강한 색 두 개를

- **현재 이씀과의 충돌:** 이씀은 지금 강조색 없음 · 세리프 디스플레이 · 2px 각진 모서리.
  강조색을 들이면 "차분함"을 일부 잃고 "생기·이벤트성"을 얻는다. 시각 방향 단계에서 다룬다.
- **미정:** 직접 기획 프로그램을 실제로 운영할 계획인지(사실관계, 소유자 확인 필요).

- **결정(소유자):** 레퍼런스처럼 **여백을 크게**. 섹션 간격 112–200px, 헤더·히어로 여백 확대, 칸막이 선(헤어라인 그리드) 대부분 제거.

  - Claude 판단으로 사진·카드 전반(공간·행사 사진·요금 칸)도 20px로 맞춤 — 히어로만 둥글면 따로 논다.

## 2026-11-11 · 홈페이지 시안 v3: 로고 자리 비움, ● / ○ 엠블럼

- **확인:** 소유자가 뺀다고 한 "기존 로고"는 세로 '이씀' 마크(v1 헤더의 코발트 마크). v2에서 이미 뺐다.
- **결정(소유자):** 헤더 로고 칸은 **비워 둔다.** 소유자가 **직접 손글씨로** 로고를 쓸 예정. 시안에는 점선 "로고 자리"만.
- **결정(소유자):** 그래픽은 소유자가 보여준 **코발트 바탕에 ● / ○를 세로로 쌓은 형태**가 더 낫다.
  → 엠블럼으로 만들어 히어로 사진 왼쪽 아래, 문의 띠(흰 바탕 반전), 푸터에 배치. 채운 원 · 사선 · 빈 원 = 기존 조각(ㅇ, /)의 변주.
- **미정:** 손글씨 로고(소유자 작업), 엠블럼의 정식 비율·이름.

## 2026-11-11 · 엠블럼 정정: 이씀 조각으로

- **정정(소유자):** 소유자가 보여준 ● / ○ 이미지는 **리오프라인의 것**이고, 그대로 쓰라는 뜻이 아니었다.
  "이런 느낌(코발트 판 위에 조각을 세로로 쌓은 것)"을 **이씀 조각으로** 하라는 뜻.
- **결정:** 엠블럼 = 코발트 판 위에 이씀 조각 네 개를 순서대로 세로로 쌓음: ㅇ(빈 원) → ㅣ(막대) → /(사선) → ㅁ(빈 사각형).
  굵기는 하나(판 너비의 7%). v3의 ● / ○ 엠블럼은 폐기.
- 배치는 v3와 같음: 히어로 사진 왼쪽 아래 · 문의 띠(반전) · 푸터.
