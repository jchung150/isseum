# 대관 규정 원문

노션에서 내보낸 대관 규정을 여기에 넣는다. 이용 안내 때와 같은 방식 —
**폴더째** 옮기면 된다. 마크다운과 그 옆의 이미지 폴더가 함께 있어야
사진이 어느 문단의 것인지 알 수 있다.

```
src/assets/rules/
  대관 규정 3a6a....md
  대관 규정/
    01.jpg
    02.jpg
```

사진이 없으면 마크다운만 넣어도 된다. 정리하면서 섹션별 폴더로 다시
번호를 매기고(`src/assets/rules/<slug>/NN.jpg`), EXIF 회전을 픽셀에 굽고,
긴 변 2000px으로 줄인다.

## 먼저 알아 둘 것 — 규정은 이미 코드에 있다

`src/data/booking.ts`의 `policyGroups`(3그룹 11항목)와 `refundSection`이
지금 살아 있는 규정이다. `/booking`의 2단계가 이걸 렌더하고, 홈 FAQ의
환불 질문도 같은 `refundSection.tiers`를 읽는다.

그래서 노션 원문을 그대로 새 파일에 옮겨 적으면 **같은 규정이 두 벌**이 되고,
한쪽만 고쳤을 때 폼과 공개 페이지가 서로 다른 말을 하게 된다. 이 저장소가
가장 피하려는 상황이다(CLAUDE.md의 "상수 하나, 리터럴 둘 금지").

정리 순서는 이렇게 된다:

1. 노션 원문과 `booking.ts`의 현재 규정을 **문항 단위로 대조**한다.
2. 달라진 곳을 소유자에게 확인받는다 — 노션이 최신인지, 코드가 최신인지.
3. 합의된 내용을 `booking.ts` **한 곳에만** 반영한다.
4. `/rules` 페이지는 그 데이터를 렌더하기만 한다. 새 카피는 쓰지 않는다.

`lastRevised`(현재 `2026. 08. 01.`)도 함께 갱신한다.

## 공개 페이지다

`/rules`는 검색에 노출된다. 현관·와이파이 비밀번호, 개인 연락처, 그것이 찍힌
사진은 넣지 않는다.
