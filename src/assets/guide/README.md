# 이용 안내 사진

`/guide`(이용 안내) 페이지에 쓰는 사진. 섹션 하나당 폴더 하나다.

## 어디에 넣나

폴더 이름은 `src/data/guide.ts`의 섹션 `slug`와 정확히 같아야 한다. 섹션 구성은
노션 원문을 옮기면서 확정되므로, 그 전까지는 이 폴더 바로 아래에 두고 파일명으로
어느 단계의 사진인지 알아볼 수 있게 해두면 된다.

```
src/assets/guide/
  entry/          ← 예: 입실
    01.jpg
    02.jpg
  equipment/      ← 예: 장비 사용
    01.jpg
```

- 파일은 **파일명 숫자순**으로 정렬된다. `01`, `02`, `09`, `10` 순서가 유지되도록
  0을 채워서 이름 붙일 것.
- 형식: `.jpg` `.jpeg` `.png` `.webp` `.avif`. Astro가 WebP로 변환하고 크기를
  줄이므로 원본을 그대로 넣으면 된다.
- **긴 변 1200~1600px이면 충분하다.** 안내 사진은 히어로처럼 크게 쓰지 않는다.
  `src/assets/`는 이미 51MB라서, 원본을 줄이지 않고 수십 장을 더하면 모든 클론이
  영구히 무거워진다 (git은 지운 뒤에도 과거 버전을 보관한다).

## 캡션과 대체 텍스트

사진마다 **무엇이 찍혔는지 한 줄**이 필요하다. 이 사이트는 모든 이미지에 의미 있는
`alt`를 요구한다(접근성 최저선). 노션 원문에서 사진 자리에
`[사진: 현관 도어록 클로즈업]`처럼 적어 주면 그대로 `guide.ts`의 캡션/alt가 된다.

## 공개 페이지라는 점

`/guide`는 검색에 노출되는 공개 페이지다. **현관 비밀번호, 와이파이 비밀번호,
개인 연락처가 찍힌 사진은 넣지 말 것.** 비밀번호는 지금처럼 이용 1시간 전
문자·카카오톡으로만 전달한다(`booking.ts`의 규정에 그렇게 적혀 있다).
